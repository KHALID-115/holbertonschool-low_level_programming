# 0x0f. C - Variadic functions

This project covers variadic functions in C: using stdarg.h (va_list, va_start, va_arg, va_end) to write functions that take a variable number of arguments.

## Files

- variadic_functions.h: header file with function prototypes
- 0-sum_them_all.c: sum_them_all, returns the sum of all its parameters
